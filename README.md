# SmartGymHub
## Requisitos del Sistema (Servidor Ubuntu)

Antes de levantar el servidor Node.js, es necesario instalar `yt-dlp` en el sistema operativo para la extracción de audio sin anuncios:


``` bash
sudo wget [https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp) -O /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
```
